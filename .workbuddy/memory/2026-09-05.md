### 教训 / 注意事项

- `McpServer` 不能跨请求复用，每个 HTTP 请求要 `new McpServer()` + `new StreamableHTTPServerTransport({ sessionIdGenerator: undefined })`，否则会抛 `Already connected to a transport`。
- `/mcp` 路由必须挂在最外层 HTTP handler 里，不能放进 `handleApi`。`handleApi` 第一行就是 `if (!url.pathname.startsWith("/api/")) return false;`，会把 `/mcp` 吞掉、fall through 到 SPA HTML。
- `@modelcontextprotocol/sdk` 的 zod raw shape 必须是 zod 对象（`z.string().optional()`），不能用 JSON Schema，否则报 `inputSchema must be a Zod schema or raw shape, received an unrecognized object`。
- TS strict 模式下，`() => void asyncFn()` 不等价于 `() => Promise<void>`，要给 `onGenerate={asyncFn}` 这种 prop 直接传引用。块体写法 `() => { void asyncFn(); }` 也是 `void`。
- 测试用 `PORT=5191 CREATOR_OS_DATABASE_PATH=/tmp/cato-e2e.db node server.mjs`，避开真实 `data/creator-os.db`。
